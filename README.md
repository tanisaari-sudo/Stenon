# Stenon

Полевое описание шурфов: чек-лист, таймер и экспорт. Работает без сети.

Названо в честь Николаса Стено, сформулировавшего закон напластования.

Открыть: https://tanisaari-sudo.github.io/Stenon/

На телефоне откройте ссылку один раз при интернете и добавьте на домашний экран —
дальше приложение работает офлайн, данные хранятся локально в браузере.

Порядок полей и словари соответствуют стандарту описания разрезов,
по которому работает агент Полемон (`razrez-algorithm.md`).

Экспорт: CSV (строка на слой, 56 колонок) и JSON, плюс вывод текстом
для копирования, если скачивание файла заблокировано.
